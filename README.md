# 💱 Currency ExchangeBot

🛠The following technologies were used in this project: Python (Libraries: Aiogram, Sqlite3, datetime, pytz, math)

📇 Brief information:
This bot allows you to exchange reliable electronic money (currency).

## Setup

- run `git clone https://github.com/kenjayevdev/obmenbot.git` copy repositories
- run `cd obmenbot` accessing repositories
- run `python -m venv env` to create virtual environment
- run `env\Scripts\activate` to activate the env
- run `pip install -r requirements.txt` to install all required packages
- Create a .env file and set ADMINS=#Telegram user ID and BOT_TOKEN=#BOT API KEY.
- run `python app.py`
